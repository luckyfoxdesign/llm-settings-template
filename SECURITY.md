# Security Policy

## Supported scope

Security fixes target the latest `main` of this workspace template, including its
scripts, agent workflows, and files under `_templates/`. Older snapshots and
applications created from the template are maintained by their respective owners.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/luckyfoxdesign/llm-settings-template/security/advisories/new).
Include the affected path or revision, reproduction steps, and expected impact.
Do not include credentials, personal data, or exploit details in public issues.

The maintainer aims to acknowledge reports within seven days and provide an
initial assessment within fourteen days. These are response targets for a
solo-maintained project, not guaranteed resolution deadlines. Please coordinate
public disclosure with the maintainer while a report is being assessed and fixed.
